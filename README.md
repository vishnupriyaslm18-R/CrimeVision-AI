# CrimeVision AI
Crime Pattern Analysis and Prediction using Machine Learning

Core project idea:
1. Historical Crime Details
2. Future Crime Trend Prediction
3. Crime Details File / Record Management

Main flow:
Historical Crime Data -> Crime Pattern Analysis -> Future Trend Prediction -> Crime Record Management

Datasets to be used:
- State-level crime data (`crimes.csv`)
- State-level violent crime data (`violent_crime_incidence.csv`)
- Detailed city-level crime data (`crime_dataset_india.csv`)

Note:
The datasets have different structures and years. They should be cleaned and aligned before any combined analysis. Do not blindly merge raw files.
